# Código de conduta

Queremos uma comunidade respeitosa e acolhedora. Ao participar (issues, pull requests, discussões), você concorda em:

- tratar todas as pessoas com respeito, sem assédio, discriminação, ameaças ou ataques pessoais;
- discutir ideias e código, não pessoas; aceitar críticas técnicas com maturidade;
- não expor dados pessoais de terceiros (IPs reais, e-mails, logs de acesso) nem segredos;
- não usar o projeto para vigilância ilegítima, perseguição ou fraude.

Comportamentos que violem estas regras podem levar a remoção de comentários, bloqueio e banimento do repositório.
Para denunciar, escreva para **contato@iplogger.com.br**.

Baseado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
